# Project Guidelines

## Working in This Repository

- Inspect the repository and its manifests before choosing tools, commands, or implementation patterns.
- Follow conventions already established by the codebase; do not assume a language, framework, or runtime that is not present.
- Keep changes focused on the requested task and avoid introducing dependencies unless they are needed.
- Run the narrowest relevant checks documented by the project, and report checks that could not be run.
- Update relevant documentation when behavior or setup changes.
